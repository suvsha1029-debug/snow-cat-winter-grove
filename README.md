# Winter Grove

Interactive Three.js winter scene, migrated from ChatGPT Sites to GitHub Pages.
The existing scene, wind/snow sliders, camera controls and animation are preserved.

Live: https://suvsha1029-debug.github.io/snow-cat-winter-grove/

Requires Node.js 22.13 or newer. Run `npm ci`, then `npm run dev` or `npm run build`.
To publish an update, copy the contents of `dist` into `docs` and commit/push.
GitHub Pages serves the main branch's `/docs` folder.
